# BalanceBot-ROS2

A self-balancing mobile robot project based on STM32, ESP32, micro-ROS and ROS2.

## Project Goals

- STM32 motor and encoder control
- IMU attitude estimation
- PID self-balancing control
- ESP32 and micro-ROS communication
- ROS2 C++ development
- LiDAR and odometry
- SLAM mapping
- Nav2 autonomous navigation

## Hardware

- STM32 controller
- ESP32 communication controller
- Encoder motors
- 6-axis IMU
- LiDAR
- Ultrasonic sensor

## Status

Project initialized. Hardware is on the way.
